# Implementation Roadmap

## Gate A — benchmark kernel
10 deterministic tasks; reset/run/grade/reset must be reproducible.

## Gate B — state-aware grading
30 tasks with deterministic state assertions and safety constraints.

## Gate C — empirical ontology pilot
Manually analyze 50–75 trajectories; revise categories before freezing labels.

## Gate D — annotation system
Failure event, root cause, causal edge, recoverability, recovery window, point of no return.

## Gate E — public MVP
150 tasks, all six application categories, >=3 trials/configuration, trajectory explorer.

## Gate F — perturbations
At least 20 unit-tested primitives spanning UI, environment, data, workflow and state perturbations.

## Gate G — paper suite
500+ tasks, >=5 trials/configuration, several strong model/agent configurations.

## Gate H — human reliability study
Double-annotated gold subset and adjudication.

## Gate I — statistics
Bootstrap CIs, per-category analysis, recovery survival curve, state-divergence/cascade analysis.

## Gate J — release
Paper, code, dataset, dataset card, hidden-test protocol, leaderboard, explorer, demo video, technical blog and project page.
